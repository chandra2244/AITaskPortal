# AI Powered Task Management Portal

## Tech Stack

Frontend:
- React
- Vite
- Tailwind CSS

Backend:
- Spring Boot
- Spring Security
- JWT Authentication

Database:
- PostgreSQL

## Features

- User Registration
- User Login
- JWT Authentication
- Create Tasks
- Delete Tasks
- Update Task Status
- AI Task Suggestion Feature
- Responsive Dashboard UI

## AI Feature

- Automatically suggests task priority
- Generates AI-based task summary

## Task Status

- TODO
- IN_PROGRESS
- DONE

## Run Frontend

cd frontend
npm install
npm run dev

## Run Backend

Run Spring Boot Application in STS

## Database

PostgreSQL
Database Name: task_portal
